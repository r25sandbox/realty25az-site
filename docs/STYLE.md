# Realty 25 AZ site style

## Voice
Write in firm voice: we and us. The owner's name belongs in About, in review quotes, in the FAQ, and as designated broker.

## Type
- Headings: Inter, weight 600 or 700, with tight letter-spacing.
- Body: Inter.
- Wordmark: Montserrat 700. Gold `#C8A96E` only on the 25.
- Do not load a serif for headings.

## Numbers
No leading zeros on step or list numbers. Write 1, 2, 3, not 01, 02, 03.

## Punctuation
No em dashes. Use a period, comma, colon, or parentheses. Keep an en dash only inside a number range.

## Quotes
One quote call-out tile per guide or article.

## Domain
The live site is `https://www.realty25az.com/`. Canonicals, the sitemap, and Open Graph URLs use that host. The 404 page stays `noindex`.

## Guide Markdown
Every guide under `/guides/` has a companion Markdown file next to its folder, for example `/guides/find-a-tenant.md`. The file matches the page: title, sections, the one quote, and this footer line: `Realty 25 AZ, North Scottsdale and nearby, https://www.realty25az.com/`. The guide page and the guides hub link to that file with the words "Get this guide as a Markdown file" (the hub may name the guide number). List every Markdown guide in `llms.txt`. A new guide is not done until its `.md` file, the hub link, the page link, and the `llms.txt` line exist.
