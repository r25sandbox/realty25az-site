# Realty 25 AZ site style

## Voice
Write in firm voice: we and us. The owner's name belongs in About, in review quotes, in the FAQ, and as designated broker.

## Type
- Headings: Inter, weight 600 or 700, with tight letter-spacing.
- Body: Inter.
- Wordmark: Montserrat 700. Gold `#C8A96E` only on the 25.
- Do not load a serif for headings.

## Numbers
No leading zeros on step or list numbers. Write 1, 2, 3, not 01, 02, 03.

## Punctuation
No em dashes. Use a period, comma, colon, or parentheses. Keep an en dash only inside a number range.

## Quotes
One quote call-out tile per guide or article.

## Preview
Each page carries `<!-- PREVIEW-NOINDEX: remove at go-live -->` and `<meta name="robots" content="noindex, nofollow">` until the live domain is connected. Remove that comment and meta in one pass at the flip. Do not add a CNAME before then.
